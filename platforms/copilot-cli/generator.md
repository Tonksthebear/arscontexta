# Copilot CLI Platform — Generation Reference

## Generator Source

The CLAUDE.md generation logic lives at `generators/claude-md.md`. Copilot CLI reads `CLAUDE.md` natively, so the same generated context file works on both platforms. No separate generator is needed for the context file itself.

## What Copilot CLI Platform Generates

A Copilot CLI deployment produces:

### 1. CLAUDE.md (Context File)

Identical to Claude Code output. Copilot CLI auto-loads `CLAUDE.md` from git root and cwd. The same feature blocks, vocabulary mappings, and personality dimensions apply.

Generated by: `generators/claude-md.md`

### 2. .github/hooks/ (Hook Configuration + Scripts)

Hook configuration and scripts adapted for Copilot CLI's format.

Configuration: `.github/hooks/arscontexta.json` (version:1, bash/powershell keys)

Scripts:
- `scripts/session-orient.sh` — Session tracking (side effects only; context injection via skill)
- `scripts/write-validate.sh` — Post-write schema logging (stdout ignored; use preToolUse for enforcement)
- `scripts/validate-pretool.sh` — Pre-write schema enforcement (can deny writes missing frontmatter)
- `scripts/auto-commit.sh` — Async post-write auto-commit
- `scripts/session-capture.sh` — Session end persistence

### 3. .github/skills/ (Processing Skills)

Skills placed in `.github/skills/` instead of `.claude/skills/`. Format is identical — `SKILL.md` with YAML frontmatter.

Additional Copilot-specific skill:
- `session-orient/SKILL.md` — Replaces hook-based context injection

### 4. .github/agents/ (Custom Agents)

Agent profiles in `.github/agents/` instead of `.claude/agents/`. Format is identical — Markdown with YAML frontmatter.

- `knowledge-guide.md` — Pipeline subagent for processing phases

### 5. MCP Configuration

MCP servers configured in `~/.copilot/mcp-config.json` (user-level) or via `/mcp add`.

For qmd-enabled systems:
```json
{
  "mcpServers": {
    "qmd": {
      "command": "qmd",
      "args": ["mcp"]
    }
  }
}
```

## Platform Characteristics

| Aspect | Detail |
|--------|--------|
| Context loading | CLAUDE.md auto-loaded by Copilot CLI |
| Hook language | Bash scripts (+ PowerShell on Windows) |
| Hook events | sessionStart, sessionEnd, preToolUse, postToolUse, userPromptSubmitted, errorOccurred, agentStop, subagentStop |
| Hook output | Only preToolUse output processed (deny decisions) |
| Skill format | .github/skills/*/SKILL.md |
| Agent format | .github/agents/*.md |
| File access | Full filesystem via Copilot CLI |
| MCP support | Yes — configured via /mcp add or mcp-config.json |

## Differences from Claude Code Platform

| Aspect | Claude Code | Copilot CLI |
|--------|------------|-------------|
| Hook context injection | SessionStart stdout → conversation | ❌ Not supported — use session-orient skill |
| PostToolUse feedback | additionalContext → conversation | ❌ Not supported — use preToolUse deny |
| Tool matchers | `"matcher": "Write"` in hook config | Filter by `toolName` in script logic |
| Async hooks | `"async": true` in hook config | Not explicitly supported |
| Plugin root | `${CLAUDE_PLUGIN_ROOT}` | `$ARSCONTEXTA_ROOT` (user-set) |
